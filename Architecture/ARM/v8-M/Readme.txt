- Armv8-M Architecture Reference Manual: 定义软件可依赖的架构行为，包括指令、寄存器、异常和内存模型，以及架构版本与可选扩展的差异。不描述 M55 或某颗 SoC 的具体实现。

- Cortex-M55 Processor Technical Reference Manual: 描述 Cortex-M55 内核的功能、组成、行为和可配置选项。某颗 SoC 实际采用了哪些可选配置，还需查阅芯片厂商资料。

- Introduction to the Armv8-M Architecture and its Programmers Model: 从软件开发视角解释 Armv8-M 的运行状态、模式、寄存器等基础概念。
