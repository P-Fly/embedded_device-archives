# embedded_device-archives

本仓库用于整理个人在嵌入式学习过程中收集的书籍、架构手册，以及学习笔记、设计方案和配套示例，便于持续积累和查阅。

## 目录导航

查看 [完整目录](SUMMARY.md)，按技术主题查找具体资料和文章。

## 内容分类

| 目录 | 内容 | 当前主题 |
| --- | --- | --- |
| [Architecture](Architecture/) | 架构、指令集、ABI 等规范性资料 | ARM ABI、ARMv7-M、ARMv8-M |
| [Books](Books/) | 嵌入式相关书籍 | Cortex-M |
| [Notes](Notes/) | 技术原理、源码分析、工具用法、设计方案和学习记录 | FreeRTOS、Keil、Base64、Zephyr、设计方案 |

## 归档约定

- 架构规范放入 `Architecture/`，书籍放入 `Books/`。
- 知识解释和工具操作放入 `Notes/` 的对应技术主题目录；以解决工程问题为主的方案放入 `Notes/Design/`，不以是否包含代码作为分类依据。
- 笔记按技术主题归档，设计方案按具体问题归档；配套图片、图稿和示例代码就近存放。
- 文章文件名保留日期和主题，新增文章时同步更新 [完整目录](SUMMARY.md)。
