# 队列集

队列集让任务通过一个阻塞点等待多个队列或信号量上的可用事件。任务等待的是队列集，不是同时挂入各成员的等待链表。成员队列有消息或成员信号量可获取时，任务可以从队列集中取得对应的成员句柄，再消费该成员的一次事件。

## 使用方法

1. 启用 `configUSE_QUEUE_SETS == 1`，使用 `xQueueCreateSet()` 显式创建队列集。该接口动态分配集合存储，要求 `configSUPPORT_DYNAMIC_ALLOCATION == 1`；创建失败返回 `NULL`。

2. 使用 `xQueueAddToSet()` 加入成员。成员必须为空，且尚未属于任何队列集；成功返回 `pdPASS`，否则返回 `pdFAIL`。同一成员不能重复加入，也不能同时属于多个集合。

3. 任务调用 `xQueueSelectFromSet()` 等待成员事件。`xTicksToWait` 以 tick 为单位，0 表示立即尝试；没有事件且等待期满时返回 `NULL`。`xQueueSelectFromSetFromISR()` 不阻塞，没有事件时立即返回 `NULL`，并须满足 port 的中断优先级限制。

4. select 返回非 `NULL` 后，识别成员类型：队列使用 `xQueueReceive()`，信号量使用公开接口 `xSemaphoreTake()`。ISR 中使用 `xQueueReceiveFromISR()` 或 `xSemaphoreTakeFromISR()`，后者仅用于支持中断上下文的二值/计数信号量，不用于互斥量。每次选择只对应一次接收或获取，通常使用零等待，并检查消费接口的返回值。

select 只移除队列集中的一个事件记录，不读取成员数据，也不减少成员信号量的计数。不能在未选择成员时绕过队列集直接消费，也不能只选择一次就连续清空该成员；否则集合中的记录与成员实际状态会失去对应关系。查看数据不消费成员事件，不能用 peek 代替配对的接收。

## 容量与成员状态

`uxEventQueueLength` 是队列集可保存的事件记录数，不是成员个数。为覆盖所有成员同时积累到上限的情况，容量至少取各成员容量之和：

| 成员类型 | 计入队列集容量的项数 |
| --- | --- |
| 队列 | 队列长度 |
| 二值信号量 | 1 |
| 计数信号量 | 最大计数 |

例如，长度分别为 5 和 12 的两个队列，加一个二值信号量，需要至少 `5 + 12 + 1 = 18` 个事件槽位。同一成员句柄可以在集合中出现多次，每个记录对应一次尚未消费的事件；集合并不按成员去重。

集合数据区每个事件槽位存储一个成员句柄，开销随容量增长，另有队列控制结构。容量不足时，即使成员操作成功，也可能无法保存对应的集合通知；不能把它当作可靠的丢弃策略。最大计数很高的信号量会占用较多集合存储，应结合事件规模选择同步方式。

加入成员时，队列消息数或信号量当前计数必须为 0。计数信号量的初始计数也受这一条件约束。成员成功加入后再允许生产者发送或释放信号量，避免加入操作与生产者并发造成失败。

## 事件传递

队列集本身也是队列，存储项是成员句柄，不是成员的消息内容。内核通过 `prvNotifyQueueSetContainer()` 把有事件的成员句柄追加到集合，并按等待和调度条件唤醒接收者；队列锁可能延后通知处理。应用只使用公开接口，不直接调用这一内部函数。

![QueueSet Receive][2]

图中 Queue1 有两条消息，因此集合中有两个 Queue1 句柄；Queue2 有一条消息，对应一个 Queue2 句柄。select 取出一个 Queue1 句柄后，还需从 Queue1 接收一条消息，不能把选中句柄当作消息已经被接收。

## 成员管理与互斥量

`xQueueRemoveFromSet()` 只在对象属于指定集合且成员为空时成功，返回 `pdPASS`；不属于该集合或成员非空时返回 `pdFAIL`。它只解除关联，不删除成员对象。

移除或删除前，应用应停止相关生产者和 ISR，按 select 与消费配对的方式处理完待处理事件，并确保没有任务仍在等待或访问即将删除的对象。删除队列集不会自动删除成员，也不会替成员清除所属集合的关联；应先移出成员，再删除集合。

互斥量作为成员时，容量按 1 计算，但任务阻塞等待队列集不会使互斥量持有者继承该等待任务的优先级，不能等同于直接阻塞获取互斥量。互斥量仍须由持有任务释放，不能在 ISR 中获取或释放。

## 替代方案

多个生产者也可以向单个队列发送带类型标记的结构体，由类型字段区分事件，其他字段保存数据或指针。这样只需一次接收；若保存指针，仍需协调对象生命周期和所有权。需要保留多个独立队列或信号量时，再考虑队列集。
